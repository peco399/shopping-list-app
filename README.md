# Shopping List App
A simple shopping list app that helps you manage your daily groceries efficiently.  
This app allows users to add, edit, and delete items, and supports multiple languages (English and Japanese).
I developed this app to practice React fundamentals, especially useState and props.  
Through this project, I also learned about component structure, state management, and data persistence using local storage.

## Features
- Add, edit, and delete items
- Save data to local storage
- Item transfer feature from Wishlist to Shopping List
- Multi-language support (English / Japanese)
- Responsive design (works on both PC and mobile)

## Built With
- HTML / CSS / JavaScript
- React (or Vue)
- LocalStorage 
- Custom translation system using JavaScript files
